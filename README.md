# Firefly Drift

A mobile arcade game: guide your firefly, beat the bosses, build a meadow with flying islands.

Play it: `https://YOUR-USERNAME.github.io/firefly-drift/` (after you turn on GitHub Pages below).

## Put it on GitHub
1. On github.com click **New repository**, name it `firefly-drift`, keep it Public, click **Create**.
2. Click **uploading an existing file**, drag in everything from this folder (index.html, manifest.webmanifest, sw.js, both icons, .nojekyll, README.md) and click **Commit changes**.
3. Go to **Settings > Pages**. Under "Build and deployment" pick **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After about a minute your game is live at the address above.

## Install it like an app
Open the address on your phone, then use the browser menu and choose **Add to Home Screen** (iPhone: Share > Add to Home Screen).

## Updating later
Replace `index.html` on GitHub with the new version. In `sw.js` change `ffd-v1` to `ffd-v2` so phones pick up the update.
